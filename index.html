收錄哪些活動？

以台灣的資安教育活動為主，包含 AIS3 新型態資安暑期課程、AIS3 Junior、AIS3 EOF CTF、MyFirstCTF、臺灣好厲駭、HITCON 台灣駭客年會、CYBERSEC 臺灣資安大會、資安技能金盾獎、全國技能競賽網路安全職類、SITCON 等課程、CTF 競賽與研討會。

怎麼訂閱截止日？

點上方「訂閱 Google 日曆」或「訂閱 Apple / Outlook 日曆」，之後新增的活動會自動同步到你的行事曆；也可以在每張卡片按「＋ Google 日曆」單筆加入。

倒數時間是哪個時區？

截止時間依主辦單位公告的時區（台灣活動為台北時間 UTC+8）計算，並以你裝置的當地時間顯示。資訊僅供參考，報名前請以主辦單位公告為準。

發現活動漏掉或資訊有誤？

歡迎到 GitHub 直接編輯 _data/conferences.yml 並送出 Pull Request，或開 Issue 告訴我們。
